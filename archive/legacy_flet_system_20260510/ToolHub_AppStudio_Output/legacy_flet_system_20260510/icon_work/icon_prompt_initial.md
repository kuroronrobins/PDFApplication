ToolHub向けの高精細な業務アプリアイコン。落ち着いた角丸スクエアの中に、インディゴとスレートを基調にした1枚のPDF書類を描き、その書類の上から右上へ向かってアンバーの光が立ち上がり、分析チャートが浮き上がるように見える構図。書類の手前に、確認済みのデータバーを示す短い棒グラフと、ページの折り返しではない固有の指標マークを少しだけ添える。入力のPDF/文書が、起動アクションによって出力のPDF/文書へつながる流れが一目で分かるよう、2〜4個の要素を明快な矢印や光の軌跡で結ぶ。マットな紙質の質感と、シャープで洗練されたチャートの対比を強調し、32pxでも主役モチーフの輪郭が判別できるように大きめで簡潔にまとめる。文字やロゴ風の記号は入れず、写真風や画面キャプチャ風にはしない。既存ToolHubアイコンと並べても違和感のない、静かな業務品質のモダンなデザイン。
