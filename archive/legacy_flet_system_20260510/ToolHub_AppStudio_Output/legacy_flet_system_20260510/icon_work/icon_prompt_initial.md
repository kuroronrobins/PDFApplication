ToolHub向けの高精細な業務用アプリアイコン。中央に、インディゴとスレートの落ち着いた帳票PDFがあり、その上からアンバーの分析チャートが立ち上がるように浮かび上がる、帳票から分析結果へ起動する流れを表現する。入力側はPDF文書としてはっきり分かる形で置き、出力側にも整ったPDF文書が見えるようにして、2〜4個の要素を一本の明確な動線でつなぐ。補助モチーフとして、ページ端の折り返しではない固有の指標マークと、確認済みを感じさせる短いデータバーを控えめに添える。マットな紙質とシャープなチャートの対比、角丸の余白、落ち着いた業務向け品質、32pxでも主役の輪郭が判別できるシンプルさ、256px以上で光沢と素材感が美しく見える精密さを両立する。写真風や画面キャプチャ風は避け、文字やロゴに頼らず、既存ToolHubアイコンと並んでも違和感のない洗練された構図にする。
