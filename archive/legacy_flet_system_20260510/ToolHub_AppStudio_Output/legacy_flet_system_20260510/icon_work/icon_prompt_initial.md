ToolHub向けの高精細な業務用アプリアイコン。中央に、インディゴとスレートの落ち着いた帳票PDFを立体的に配置し、そこからアンバーの分析チャートが上向きに浮かび上がる様子を表現する。左側に入力PDF、右側に出力PDFを2〜4枚の意味のあるオブジェクトで示し、中央の「起動」を感じさせる明確な矢印や光の流れで、pdf/document → launch → pdf/document の関係が一目で分かる構図にする。補助モチーフとして、ページ端の折り返しではなく固有の指標マークと、確認済みのデータバーをさりげなく加える。マットな紙質とシャープなチャートの対比を強調し、角丸の余白を十分に取った整然としたレイアウトにする。32pxでも主役モチーフの輪郭が判別できるように簡潔で読みやすく、256px以上では輪郭、光沢、余白、素材感が美しく見える洗練された仕上げ。写真風や画面キャプチャ風にはせず、読めない文字やロゴ風文字は入れない。
