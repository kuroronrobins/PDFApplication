ToolHub向けの高精細な業務用アプリアイコン。中央に、インディゴとスレートのPDF書類が開き、その上にアンバーの分析チャートが立体的に浮かび上がるシンボルを配置する。左側に入力PDF、右側に編集後のPDFを示す2〜4個の要素を、一本の明確な起動フローでつなぎ、起動アクションが一目で分かる構図にする。ページ端の固有の指標マークや、確認済みを示す控えめなデータバーを補助的に入れる。マットな紙質とシャープなチャートの対比を強調し、角丸の余白で整えた落ち着いた業務向けデザインにする。32pxでも主役モチーフの輪郭が判別できるように簡潔に、256px以上では輪郭や素材感が美しく見える高精細仕上げ。写真風や画面キャプチャ風にはせず、読める文字やロゴ文字は入れない。
